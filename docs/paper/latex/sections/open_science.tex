\section*{Open Science}

We release the full experimental pipeline needed to regenerate this
corpus and every reported result, not only a static data dump.

\textbf{Git-tracked and released with the paper:} the 30 human-approved
synthetic scenario specifications (24 poisoned across four
\texttt{poison\_form} styles, 6 clean controls), the frozen
experimental grid (\texttt{configs/experiment\_grid.yaml}), the
generation harness (\texttt{eval/run\_full\_sweep.py},
\texttt{src/memoryir/harness.py}), the labeling pipeline
(\texttt{src/memoryir/labeler.py}), and all metric/bootstrap/figure
code (\texttt{eval/compute\_*.py}, \texttt{eval/bootstrap\_*.py},
\texttt{eval/make\_figures.py}). The 20-scenario real-document
validation slice is released the same way: its scenario specifications
(\texttt{configs/scenarios/real\_documents/}), frozen source-document
manifest with SHA-256 hashes (\texttt{real\_documents/manifest.yaml}),
generation and labeling runners (\texttt{eval/}\allowbreak
\texttt{run\_real\_document\_validation.py}, \texttt{eval/}\allowbreak
\texttt{label\_real\_document\_validation.py}), metric script
(\texttt{eval/compute\_real\_document\_metrics.py}), and compact
results tables and manual-review file
(\texttt{results/real\_document\_validation/}). Every generation run's
provenance (git commit, full config snapshot) is recorded in
\texttt{results/full\_sweep/}\allowbreak\texttt{run\_meta\_*.json}
(main corpus) and \texttt{results/real\_document\_validation/}\allowbreak
\texttt{run\_meta\_*.json} (real-document slice).

\textbf{Not git-tracked, but regenerable from the above:} the raw
generated memories, embeddings, and labels (216,319 derived memories
across 3 models for the main corpus; 2{,}400 for the real-document
slice), which live in Postgres. Given API access to the same three
model endpoints (gpt-4o-mini, gpt-4o, Llama-3.3-70B-Instruct, using the
API versions reported in \S\ref{sec:harness}) and the released
scenario specs and grid, the corpus is regenerable end to end via the
seven-step pipeline documented in \texttt{eval/README.md}, using the
released pipeline and pinned API versions; exact byte-identical
outputs are not guaranteed, since hosted-model inference at
temperature 0 is not itself guaranteed to be deterministic across
requests or over time. We additionally release summary CSVs
(\texttt{results/metrics/}, \texttt{results/real\_document\_validation/})
and figures (\texttt{results/figures/}) so results can be checked
without regenerating the full corpus.

\textbf{Missing data is documented, not hidden.} 30 of 21,600 planned
traces (0.14\%) are permanently missing---all Llama-3.3-70B-Instruct,
rejected by the platform's content-safety filter---and are left as
genuine missing data rather than imputed.

API-key-bearing logs are redacted at generation time and never included
in any release.
